# Power and sensitivity analyses

Minimum detectable AUC (MDES) under α = 0.05 two-sided and power = 0.80/0.90, using the Hanley–McNeil bi-normal equal-variance model; stronger clinical baselines (age + sex + temporal-lobe involvement + tumour volume ± oedema volume) with calibration slope and intercept; and sensitivity analyses stratified by cohort composition and by acquisition geometry.

Entry point: `power_mdes_and_review_analyses.py`
